# Knowledge Base Sources - Websites to Expand MSME Chatbot Knowledge

This document lists authoritative Indian government websites and resources that should be used to expand the knowledge base for the MSME Business Support Chatbot.

## Core Government Portals

1. **MSME Ministry Official Portal**

   - Content: Policies, schemes, announcements, statistics

   - URL: https://udyamregistration.gov.in/

## Data Collection & Update Strategy

### Recommended Update Frequency
- **High Priority** (Weekly): GST, tax rates, new schemes
- **Medium Priority** (Monthly): Application procedures, documentation
- **Low Priority** (Quarterly): General information, background content

### Content Extraction Method
1. **Official PDFs**: Download scheme documents, guidelines
2. **FAQ Pages**: Extract Q&A format content
3. **Circulars/Notifications**: Latest policy changes
4. **Tutorial Videos**: Transcribe step-by-step processes
5. **Helpdesk Info**: Contact details, support information

### Content Structure for Knowledge Base
```
Topic: [e.g., MUDRA Loan - Shishu Category]
Source: [URL]
Last Updated: [Date]
Content:
- Overview
- Eligibility Criteria
- Required Documents
- Application Process
- Interest Rates & Terms
- Frequently Asked Questions
- Contact Information
- Related Links
```

## Implementation Notes

### Priority Order for Expansion
1. **Phase 1** (Critical): MUDRA, GST, Udyam, PMEGP
2. **Phase 2** (Important): GeM, CGTMSE, Stand-Up India, Labor laws
3. **Phase 3** (Additional): Export/Import, IP, State schemes

### Quality Assurance
- Verify information from official sources only
- Cross-reference with multiple government portals
- Include effective dates for time-sensitive information
- Mark deprecated/outdated schemes clearly
- Include language versions (Hindi, regional languages)

### Multilingual Content
Many portals offer Hindi/regional language versions:
- Prioritize bilingual content extraction
- Ensure translations maintain technical accuracy
- Include common vernacular terms for searchability

## Maintenance Schedule

- **Monthly**: Review all financial scheme portals
- **Quarterly**: Comprehensive audit of all content
- **Annual**: Major knowledge base refresh
